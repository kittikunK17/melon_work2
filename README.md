# ตะวันฟาร์ม V2 — เว็บไซต์เมลอนหนองคาย

เว็บหน้าเดียวของตะวันฟาร์ม (บ้านตะวันรีสอร์ท) รองรับภาษาไทย/อังกฤษ มือถือ และโหมดมืด
ไม่ต้องติดตั้งอะไร ไม่มีระบบหลังบ้าน อัปโหลดขึ้น GitHub Pages ได้ทันที

---

## โครงสร้างไฟล์

```
tawan-farm-site/
├── index.html          ← โครงหน้าเว็บ (ปกติไม่ต้องแก้)
├── css/style.css       ← หน้าตา สี ฟอนต์ (สีหลักอยู่บนสุดของไฟล์)
├── js/content.js       ← ★ ข้อมูลทั้งหมดของเว็บ แก้ไฟล์นี้ไฟล์เดียว
├── js/main.js          ← การทำงานของเว็บ (ไม่ต้องแก้)
├── images/
│   ├── favicon.svg     ← ไอคอนบนแท็บเบราว์เซอร์
│   ├── share.jpg       ← (ใส่เพิ่มเอง) รูปตอนแชร์ลิงก์ใน LINE/Facebook
│   ├── melons/         ← รูปเมลอนแต่ละพันธุ์ melon-1.jpg ถึง melon-5.jpg
│   └── farm/           ← รูปบรรยากาศสวน farm-1.jpg
└── robots.txt
```

## 1. ใส่รูปเมลอนและรูปสวน

1. ถ่ายรูปด้วยมือถือ แนวนอน (สัดส่วน 4:3) แสงเช้าหรือเย็นจะสวยที่สุด
   - เมลอนแต่ละพันธุ์: ถ่ายทั้งลูก + ผ่าครึ่งให้เห็นเนื้อ อยู่ในรูปเดียวกัน
   - สวน: มุมกว้าง เห็นแปลงหรือโรงเรือน
2. ย่อขนาดรูปที่ **https://squoosh.app** → ลากรูปเข้าไป → เลือก MozJPEG, Quality 75,
   Resize กว้าง 1200 → ดาวน์โหลด (ควรได้ไฟล์ไม่เกิน 300 KB เว็บจะโหลดเร็ว)
3. เปลี่ยนชื่อไฟล์ให้ตรงตามนี้ (ตัวเล็กทั้งหมด):
   - `images/melons/melon-1.jpg` … `melon-5.jpg` (เรียงตามลำดับพันธุ์ใน content.js)
   - `images/farm/farm-1.jpg` (V2: รูปแนวตั้ง 4:5 เช่น 1080 x 1350)
4. เอาไฟล์ไปวางในโฟลเดอร์นั้น เสร็จแล้ว — ไม่ต้องแก้โค้ด
   รูปไหนยังไม่มี เว็บจะแสดงภาพวาดแทนให้เอง

**อยากใช้ชื่อไฟล์อื่น หรือใช้ .png / .webp?** เปิด `js/content.js` แล้วแก้บรรทัด `photo: '...'`
ให้ตรงกับชื่อไฟล์ เช่น `photo: 'images/melons/greennet.webp'`

**รูปแชร์ลิงก์:** ทำรูปขนาด 1200 x 630 ชื่อ `share.jpg` วางใน `images/`
(ทำใน Canva ได้ เลือกขนาด "Facebook Post (Landscape)")

## 2. แก้ข้อมูลเมลอน / เบอร์โทร / ข้อความ

เปิด `js/content.js` แก้ได้เลย มีคำอธิบายภาษาไทยในไฟล์

- **ชื่อและรายละเอียดเมลอน:** อยู่ในส่วน `melons:` แต่ละพันธุ์มีทั้ง `th:` (ไทย) และ `en:` (อังกฤษ)
  ช่องไหนปล่อยว่าง `''` เว็บจะซ่อนช่องนั้นให้ ถ้าภาษาอังกฤษยังว่าง จะใช้ภาษาไทยแทน
- **เพิ่มพันธุ์ที่ 6:** ก๊อปปี้ก้อน `{ photo: ... }` ทั้งก้อน วางต่อท้าย แล้วใส่รูป `melon-6.jpg`
- **เบอร์โทร / ที่อยู่ / ลิงก์แผนที่:** อยู่บนสุดของไฟล์
- **ข้อความอื่นบนเว็บ:** อยู่ในส่วน `text:` ด้านล่าง

ข้อควรระวัง: แก้เฉพาะข้อความใน `'...'` อย่าลบ `'` `,` `{` `}` ถ้าเว็บขึ้นหน้าว่าง
แปลว่าพิมพ์เครื่องหมายหาย ให้ย้อนดูจุดที่เพิ่งแก้

**ลองดูบนเครื่องก่อนอัปโหลด:** ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย
(หรือใน VS Code ใช้ส่วนขยาย Live Server)

## 3. เอาขึ้นเว็บด้วย GitHub Pages (ฟรี)

ทำครั้งแรกครั้งเดียว:

1. เข้า https://github.com → กด **New repository**
   - ชื่อ: `tawan-farm` · เลือก **Public** · กด **Create repository**
2. ในหน้า repo ใหม่ กด **uploading an existing file**
   → ลากไฟล์และโฟลเดอร์ *ข้างใน* `tawan-farm-site` ทั้งหมดเข้าไป
   (ต้องเห็น `index.html` อยู่ชั้นนอกสุดของ repo) → กด **Commit changes**
   หรือถ้าใช้ git: `git init`, `git add .`, `git commit -m "Tawan Farm website"`,
   `git branch -M main`, `git remote add origin https://github.com/<ชื่อผู้ใช้>/tawan-farm.git`, `git push -u origin main`
3. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → **Save**
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/tawan-farm/`
5. (ทำครั้งเดียว) เปิด `index.html` หาบรรทัด `og:image` แล้วเปลี่ยน `images/share.jpg`
   เป็นลิงก์เต็ม เช่น `https://<ชื่อผู้ใช้>.github.io/tawan-farm/images/share.jpg`
   รูปตอนแชร์ลิงก์ใน LINE/Facebook ถึงจะขึ้น

อัปเดตครั้งต่อไป (ใส่รูป แก้ข้อมูล):
- เข้า repo บน GitHub → เข้าโฟลเดอร์ที่ต้องการ → **Add file → Upload files** (สำหรับรูป)
  หรือกดไฟล์ `js/content.js` → ไอคอนดินสอ ✏️ แก้แล้ว **Commit changes**
- รอ 1–2 นาที แล้วรีเฟรชหน้าเว็บ (ถ้ายังไม่เปลี่ยน กด Ctrl+Shift+R)

## 4. ให้คนค้นเจอใน Google ("เมลอนหนองคาย")

เว็บตั้งค่า SEO พื้นฐานไว้แล้ว (ชื่อหน้า คำอธิบาย ข้อมูลร้านแบบที่ Google อ่านได้) ที่ต้องทำเพิ่ม:

1. **Google Business Profile** (สำคัญที่สุดสำหรับร้านท้องถิ่น) — https://business.google.com
   ลงทะเบียน "ตะวันฟาร์ม" ใส่ที่อยู่ เบอร์ รูป และลิงก์เว็บนี้ ร้านจะขึ้นในแผนที่และผลค้นหา
2. **Google Search Console** — https://search.google.com/search-console
   เพิ่มเว็บของคุณ แล้วกด "ขอให้จัดทำดัชนี" Google จะรู้จักเว็บเร็วขึ้น
3. แชร์ลิงก์เว็บใน LINE, Facebook, กลุ่มท่องเที่ยวหนองคาย ยิ่งมีคนลิงก์มามาก ยิ่งติดอันดับง่าย

## 5. ต่อโดเมนของตัวเองภายหลัง (เช่น tawanfarm.com)

1. ซื้อโดเมนที่ Cloudflare, Namecheap หรือผู้ให้บริการไทย (ประมาณ 300–500 บาท/ปี)
2. GitHub repo → **Settings → Pages → Custom domain** → พิมพ์ `tawanfarm.com` → Save
3. ที่ผู้ขายโดเมน ตั้งค่า DNS ตามที่ GitHub แนะนำ (A record 4 ตัว + CNAME `www`)
   ดูขั้นตอนเต็ม: https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site
4. ติ๊ก **Enforce HTTPS**
