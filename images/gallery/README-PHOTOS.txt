วางรูปสำหรับส่วน "รูปและวิดีโอจากสวน" ในโฟลเดอร์นี้ ตั้งชื่อไฟล์ตามนี้:

  photo-1.jpg, photo-2.jpg, photo-3.jpg ... (กี่รูปก็ได้)
  video-1.jpg, video-2.jpg  = รูปหน้าปกของวิดีโอ (ไม่ใส่ก็ได้)

- ชื่อไฟล์ต้องตรงกับที่เขียนไว้ใน js/content.js ส่วน gallery
  ถ้ามีรูปมากกว่า 6 รูป ให้เพิ่มบรรทัดใน content.js เช่น
  { type: 'photo', src: 'images/gallery/photo-7.jpg', th: '', en: '' },
- รูปแนวนอน 4:3 สวยที่สุด (เช่น 1200 x 900 พิกเซล)
- ย่อขนาดไฟล์ให้ไม่เกิน 300 KB ที่ https://squoosh.app
- รูปไหนยังไม่มี เว็บจะไม่แสดงช่องนั้น (ไม่เสียหน้าเว็บ)
